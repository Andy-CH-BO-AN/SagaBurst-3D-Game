# SagaBurst Career Mission Voice Pack v1

Eight faction mission cues plus one Town Defense alarm, imported from the
provided `sagaburst_core_voice_v1.zip`. `manifest.json` maps paths to transcripts.

All WAV files are 44.1 kHz, mono, 16-bit PCM. The supplied alarm was converted
from 48 kHz stereo to match this format; the eight voice clips are unchanged.

This pack loads on Career mission events only. V3 battle commands remain in
`sagaburst_audio_pack_v3`.
