# SagaBurst v1.0.0

The first public release of SagaBurst brings Viking and Roman battles to your browser and desktop.

## Play

- **Browser:** [Play Online](https://andy-ch-bo-an.github.io/SagaBurst-3D-Game/) on a desktop computer with keyboard and mouse.
- **Windows x64:** download `SagaBurst-v1.0.0-Windows-x64.zip`, extract the entire folder, and open `SagaBurst.exe`.
- **macOS Apple Silicon:** download **`SagaBurst-v1.0.0-macOS-arm64-fixed.zip`**, extract it, move `SagaBurst.app` to Applications, and follow `MACOS-FIRST-LAUNCH.txt`. This is the repaired macOS download; the original ZIP had invalid signatures.

No Node.js, npm or Git is needed. Desktop builds include the game assets and work offline. The unnotarized macOS build may need a one-time Terminal command described below.

## What's playable

- Custom Viking vs Roman battles with up to 200 AI troops per side, infantry, ranged units and cavalry. Fight in person, command your army, or spectate.
- Roman and Viking Defense Campaigns, each with nine stages and separate saved progression.
- Career Mode: explore a fortified faction town, earn merit and promotions, complete missions, and purchase equipment and mounts.
- Personal Squads and the HR Center for officers, plus Town Defense and Enemy Town Assault missions.
- Mounted combat and Black Cat / Corgi free rides.

## First launch and saves

The repaired macOS ZIP has complete ad-hoc signatures for the App, frameworks and helpers, but is not Apple-notarized. Open once, then use **System Settings → Privacy & Security → Open Anyway**. If macOS still reports “damaged”, after moving the app to Applications run:

```bash
xattr -dr com.apple.quarantine "/Applications/SagaBurst.app"
open "/Applications/SagaBurst.app"
```

This applies only to SagaBurst; it does not disable Gatekeeper for other apps. Windows is unsigned and may show Microsoft Defender SmartScreen; use More info → Run anyway for this official GitHub download.

The macOS packaging repair leaves the v1.0.0 game and save formats unchanged. It is an additional download in this same release; the original files and version tag remain intact.

Career and Campaign saves stay on the device. Browser saves and desktop saves are separate and do not sync. Clearing site data or deleting the app's user data removes saves. Click the game view to capture the mouse; press Esc to release it.
