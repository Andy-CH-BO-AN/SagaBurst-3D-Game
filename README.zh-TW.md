# SagaBurst 3D Game

[English](./README.md) | **繁體中文**

加入 Viking 與 Roman 的大型戰鬥、指揮部隊、培養自己的軍旅生涯，也能騎著巨鷹飛上天空。**SagaBurst** 是一款使用鍵盤與滑鼠、適合桌上型電腦遊玩的 3D 動作遊戲。

## 開始遊玩

[**直接在瀏覽器玩**](https://andy-ch-bo-an.github.io/SagaBurst-3D-Game/) · [**下載桌面版**](https://github.com/Andy-CH-BO-AN/SagaBurst-3D-Game/releases/latest)

本說明以儲存庫目前版本為準；線上版與桌面發行版可能尚未包含所有玩法。

- **Windows x64：**完整解壓 ZIP 後開啟 `SagaBurst.exe`，請保留解壓後的整個資料夾。
- **macOS Apple Silicon：**解壓 ZIP，將 `SagaBurst.app` 移到「應用程式」，依隨附的[首次開啟說明](./MACOS-FIRST-LAUNCH.txt)操作。程式尚未經 Apple 公證，可能需要到「系統設定 → 隱私權與安全性 → 強制打開」。
- Windows 版未做程式簽署，可能顯示 SmartScreen；確認信任官方下載後，可選「其他資訊 → 仍要執行」。

桌面版包含遊戲資產，可以離線遊玩，不需要安裝開發工具。

點擊遊戲畫面即可鎖定滑鼠、操作鏡頭。`Esc` 會釋放游標；Career 與訓練場還有暫停選單。

## 新手快速上手

建議從主選單的 **Career 生涯模式**開始：

1. **選陣營、建立角色。**先進入新兵訓練場，跟著畫面提示練習移動、`Tab` 裝備、近戰、盾牌、弓箭與騎馬。完成後會領取 100 軍功，並自動返回城鎮。
2. **買第一把武器。**到城鎮的武器店購買，買好後按 `Tab` 開啟背包裝備。靠近 NPC 按 `E` 交談。
3. **找士官長接任務。**從新兵任務開始（例如剿匪），順著畫面下方的箭頭走，跟隨隊長行動。
4. **累積軍功、晉升。**戰鬥與競賽都能賺軍功；軍功達標後，到指定 NPC 接受任命。
5. **擴充實力。**買馬、招募私兵、挑戰更高階的任務。

想先熟悉操作，可選 **Training Ground 訓練場**；想自己配置兩軍對戰，選 **Custom Battle 自訂戰鬥**。

### 戰鬥提示

- **弓箭：**按住右鍵瞄準、按住左鍵拉弓、放開左鍵射擊；Pilum 是瞄準時點擊左鍵投擲。
- **盾牌：**只有實際命中盾牌的攻擊才會被擋下；側面與背面仍可能打中身體，盾牌也有有限的戰鬥耐久。
- 遠程武器與盾牌不能同時裝備，滾輪切換會自動收起衝突的物品。
- 戰場營地可取得裝備、彈藥與備用戰馬。

### 騎乘 xongkoro 巨鷹

按 **`W` 起飛**，用**滑鼠轉向**、**`A`／`D` 轉彎**，按住 **`Shift` 加速**。巨鷹飛行時會持續向前，按住 **`S` 減速**，接近開闊地面、降低高度後降落，再安全下鷹。空中也能離開坐騎，但角色會墜落。

未瞄準時按左鍵發動巨鷹攻擊。持有遠程武器時，按住右鍵進入騎手視角，再照一般方式射擊。瞄準可在有限角度內自由轉動；接近角度邊緣時，也會帶動巨鷹轉向。

## 遊戲模式

### Career 生涯模式

建立 Roman 或 Viking 角色，沿著 **新兵 → 士兵 → 老兵 → 隊長 → 指揮官**晉升。

靠近功能 NPC 按 `E` 交談（騎乘時也可以）。商店可買賣武器、盾牌與坐騎；按 `Tab` 開啟角色、背包與已解鎖的部隊換裝分頁。

#### 新手教學

新角色先到練習場，依序練習視角與移動、`Tab` 裝備、近戰、盾牌、弓箭、上馬與騎乘下馬。提示位於指北針下方；按 `Esc` 顯示游標後，仍可使用教學的重置、重試與稍後繼續按鈕。完成後會領取一次性的 **100 軍功**並返回城鎮，借用的裝備與馬留在練習場；可稍後繼續，再找城鎮的**士官長**恢復。

回城後跟著指標找士官長：購買第一把武器可領一次 **20 軍功**，再與騎兵隊長進行新兵切磋（勝利 500、正常失敗 20 軍功，不影響正式 1v1 解鎖）。完成兩次正式戰鬥任務、軍功也足以買普通馬時，士官長會介紹馬店，首次購馬可領一次 **50 軍功**。

首次正式接受**隊長**任命後，可找士官長進行 30 人的指揮演練，再到**人力資源中心**招募私兵並練習下令；首次正式接受**指揮官**任命後，會有登上指揮塔、下達全軍防禦的教學。

教學進度隨角色保存，可稍後繼續或重播，重播不重複發獎；舊角色保留原有進度。教學演練不計正式任務勝場，也不消耗正式部隊或私兵。

#### 軍功與任命

戰鬥貢獻與競賽勝利都能賺軍功。任命依**本次入伍累積的軍功**核定，花掉可用軍功不會讓資格或軍階倒退。達標後還需要**親自找對應 NPC 接受任命**。

| 軍階 | 所需累積軍功 | 任命來源 |
| --- | --- | --- |
| 新兵 | 0 | 初始軍階 |
| 士兵 | 300 | 騎兵隊長 |
| 老兵 | 900 | 騎兵隊長 |
| 隊長 | 5,000 | 騎兵隊長 |
| 指揮官 | 20,000 | 城鎮指揮官 |

指揮官可使用 T5 裝備，接受任命時會獲得陣營對應的 **T5 劍或斧**。

#### 任務

找**士官長**接任務。任務依軍階分頁；晉升後仍可重玩先前階級的任務。任務清單會寫明我方與敵方人數、目標，以及無法接取時需要做什麼。

| 分頁 | 內容 |
| --- | --- |
| 新兵／士兵 | 剿匪、巡邏、騎兵清剿、前哨防守、騎兵救援、進攻敵城、遭遇鐵騎。完成前哨防守 I–III 可解鎖騎兵救援，救援勝利後解鎖進攻敵城。 |
| 老兵 | 一系列依序解鎖的野戰與前哨任務、老兵守城、鐵騎破陣。 |
| 隊長 | **Captain I–VI**：巡邏指揮、騎兵清剿、城門防衛、前線指揮官、攻城隊長、巨鷹空戰，另有鋼鐵雪崩。 |
| 指揮官 | **Commander I–VII**（見下表）。 |
| 1v1 單挑 | 選擇兵種，依序挑戰 T1 到 T5。每場五秒準備、30 秒戰鬥；擊敗一階才會解鎖下一階。T5 由城鎮指揮官出戰，隊長擔任裁判。 |

| 指揮官任務 | 目標 |
| --- | --- |
| I · Sky Raid 空襲敵城 | 率領 T4 遊俠乘巨鷹空降敵城，擊倒 100 名敵城人員。 |
| II · Operation Decapitation 斬首行動 | 與前任指揮官及 T4 騎兵攻入敵城，擊敗敵方 T5 指揮官。 |
| III · Outpost Last Stand 前哨決戰 | 部署四隊步兵守住前哨，全殲 100 名敵方騎兵。 |
| IV · Bridgehead Battle 橋頭決戰 | 在北岸部署八隊步兵，守住石橋，擊退 300 名敵方騎兵。 |
| V · Four-Gate Town Defense 四門總攻守城戰 | 守住所屬城鎮，迎擊 280 名敵軍與八台攻城坡道車；守住 15 分鐘或提前全殲敵軍即獲勝。 |
| VI · Six Feline Cavalry 六貓騎兵團 | 率領 200 名貓騎遊俠，迎戰 300 名戰馬騎兵。 |
| VII · Iron Legion 鐵甲軍團決戰 | 率領同一支貓騎軍團，迎戰 300 名鐵甲重騎兵。 |

任務結束後的結算畫面會列出擊殺、傷害與各項軍功。

**戰鬥技能**與**野外遭遇**：培養單手武器、雙手武器、遠程、騎馬衝撞、格擋五項技能（各最高 50 級）；沒有接任務時，城鎮巡邏隊、盜匪、敵對地面部隊與巨鷹巡邏隊也會在城外相遇並交戰。

#### 商店與坐騎

商店可以買賣武器、盾牌與坐騎，介面會顯示價格、你持有的數量與尚未分配的數量，以及買不起或不能買的原因。已裝備或已分配給士兵的物品不能賣出，請先卸下。買好後按 `Tab` 裝備或召喚。

地面坐騎沒有軍階限制，任何階級都能買、能騎。

| 坐騎 | 價格（軍功） |
| --- | --- |
| 軍用戰馬 | 200 |
| 黑貓／白貓／橘貓／柯基 英雄坐騎 | 4,000 |
| 藪貓／獰貓 英雄坐騎 | 6,000 |
| 重甲戰馬 | 8,000 |
| 重甲雪豹 | 9,000 |
| xongkoro 巨鷹（隊長／指揮官限定，最多持有 3 隻） | 10,000 |

隊長或指揮官可找**巨鷹訓練場主**購買 xongkoro；在開闊的起降區召喚後，就能飛越戰場、用巨鷹攻擊，或在鷹背上使用遠程武器。

#### 帶領自己的部隊

- **隊長：**在城鎮指揮 **30 人城防指揮隊**。
- **指揮官：**指揮**八支正式地面小隊**，北、南、東、西四門各有一隊步兵及一隊騎兵。城鎮原生巨鷹巡邏隊與瞭望塔弓兵會自主防守。
- **私兵（Personal Squad）：**隊長或指揮官可到**人力資源中心**招募，最多 **30 人**，可選士兵、T4 隊長與 T4 遊俠；指揮官還能招募 **T5 指揮官**。從持有庫存分配武器、盾牌與坐騎，按 `Q` 選擇私兵部隊（快捷鍵 `9`）下令 **Follow me 跟隨**出隊；回城後下令 **Dismiss 收隊**，才能整補、換裝或遣散。**遣散會讓隊員帶著目前的裝備離開，裝備不會回到背包**，想保留請先卸下。
- **平民小隊（Civilian Squad）：**指揮官在所屬城鎮也能對可用的平民及商人分組下令；Dismiss 讓他們返回原本工作。

正式任務會另外授予指揮權與部隊名單，請以命令 HUD 顯示的編組為準。任務期間可能限制換裝；和平時可找人資官整補私兵，或找士官長整補可用的城鎮小隊。

#### 繞城坐騎競賽

找**士官長 → 1v1 → 繞城賽馬 Racing**，參加八場對抗城鎮指揮官的競賽。報名時需騎著**自有、存活且可用的地面坐騎**，xongkoro 不能參賽。競賽沒有軍階門檻。

跟隨隊長到北門，在 **10 秒倒數**結束前留在城門內側的起跑區。起跑後從北門出城，沿城外**東 → 南 → 西**繞行，再由北門入城，依序通過**五個檢查點**；穿越城內抄近路會失去合法完賽資格。報名後，雙方都可以下馬、改騎附近可用的地面坐騎，或在坐騎死亡後繼續徒步；即使走回終點，只要先合法完賽就能獲勝。你每場都能按 `Shift` 衝刺。

| 賽事 | 對手坐騎 | 對手速度 | 勝利軍功 |
| --- | --- | --- | --- |
| I | 戰馬 | 一般 | 100 |
| II | 柯基 | 一般 | 400 |
| III | 重甲雪豹 | 一般 | 900 |
| IV | 黑貓 | 一般 | 1,600 |
| V | 戰馬 | 衝刺 | 2,500 |
| VI | 柯基 | 衝刺 | 3,600 |
| VII | 重甲雪豹 | 衝刺 | 4,900 |
| VIII | 黑貓 | 衝刺 | 6,400 |

競賽結果與個人最佳完賽時間都會保存。舊存檔已接受的賽事保留原名稱與獎勵。

#### 申請退休

累積 **10 場指揮官任務勝利**，並至少贏過一次**四門總攻守城戰**後，可找城鎮的**指揮官**選擇**申請退休**。申請前須先完成目前任務或競賽，並讓城鎮處於和平狀態。接受前請閱讀遊戲內的確認說明，之後依畫面引導操作。

### Training Ground 訓練場

自由練習，不消耗軍功、不影響 Career 進度，也不累積戰鬥 XP。

- 試用所有武器、盾牌與坐騎（戰馬、重甲戰馬、各種貓科、柯基、xongkoro 巨鷹）。
- 對 **0–100 公尺的假人**練習近戰與射擊，查看最近一次命中的傷害。
- 利用標示的射擊點與 **125 公尺衝撞跑道**練習遠程攻擊及騎乘衝鋒。
- 按 `Tab` 開啟裝備；使用 **Refill 補給**補充物資，或 **Reset Training 重置**恢復場地。
- 在 `Esc` 選單切換一般戰士或 **T4 Shadow Warden 遊俠**；切換角色會返回起點。

### Custom Battle 自訂戰鬥

自由配置 Viking vs Roman 戰場。

- 雙方各可設定 **1–200 名 AI 士兵**，混合步兵、弓兵、標槍兵、騎兵與弓騎兵。
- 一般兵種有 **T1 / T2 / T3**，每方還可加入最多 **三名 T4 英雄**；英雄計入設定的 AI 總人數。
- 選擇 **Formation Battle 列陣戰**或 **Scattered Battle 散兵戰**，並以 **Preset 兵種**或 **Squad 小隊**分組下令。
- 選擇玩家陣營、武器、盾牌、角色與坐騎，也能開啟 **Spectator 觀戰**。玩家角色可選 T1–T3 一般士兵或 T4／T5 英雄，與 AI 軍隊的三名英雄上限分開計算。
- 使用 Squad 分組時，開戰前可編成最多**十隊、每隊最多 50 人**的小隊。
- 玩家是額外加入的角色，不計入 AI 人數。死亡後可繼續觀戰；按 **REMATCH** 用相同設定再戰。

### Defense Campaign 防守戰役

選擇 **Roman Defense** 或 **Viking Defense**，防守陣營前哨站；**每個陣營各有九關**。

- 出戰前先編成守軍小隊（可額外加入最多一名 T4 英雄，玩家不占名額），進場後有 **60 秒部署時間**，倒數結束才開始敵軍進攻。
- 守住營門、圍牆與城牆步道，迎擊敵軍及移動攻城坡道車。進攻開始 **120 秒後**，會有 **50 名友軍騎兵**趕來增援。
- 全殲攻軍即可立即獲勝；若援軍出現前，玩家與原始守軍已全滅，就會鎖定敗北，之後仍可觀戰。
- 勝利後解鎖下一關，Roman 與 Viking 的進度分開保存。

### Units & Weapons 兵種與武器

從主選單開啟 **Units & Weapons**，查看兵種特性、戰鬥數值、武器與盾牌資料，再決定裝備配置。

## 軍隊命令

按 **`Q`** 將滾輪切到命令模式，用滾輪選擇兵種或小隊，按**滑鼠中鍵**確認，再用同樣方式選命令並下令。命令子選單或列陣中按 `Q` 可關閉／取消；在子選單外按 `Q` 則切換命令與武器選擇。**反引號**（<kbd>&#96;</kbd>）可直接開啟 **ALL 全軍**命令，也能關閉已開啟的命令子選單。

也能用鍵盤直接選目標。在 **Preset 兵種分組**下：

| 按鍵 | Viking | Roman |
| --- | --- | --- |
| `1` | 資深戰士 Veteran | 重裝步兵 Heavy Infantry |
| `2` | 槍兵 | 槍兵 |
| `3` | 弓兵 | 弓兵 |
| `4` | 刀騎兵 | 標槍兵 |
| `5` | 槍騎兵 | 刀騎兵 |
| `6` | 弓騎兵 | 槍騎兵 |
| `7` | — | 弓騎兵 |
| <kbd>&#96;</kbd> | ALL 全軍 | ALL 全軍 |

在 **Squad 小隊分組**下，`1`–`8` 選擇對應的正式小隊。指揮官在所屬城鎮時，`1`／`2` 為北門步兵／騎兵，`3`／`4` 為南門，`5`／`6` 為東門，`7`／`8` 為西門。Career 用 `9` 選**私兵部隊**，`0` 選可用的**平民小隊**；任務中的正式編組則依任務而異。命令只適用於授權給你的部隊，附近友軍不會自動成為你的指揮對象。

選好目標後：

| 按鍵 | 命令 | 效果 |
| --- | --- | --- |
| `1` | Attack 攻擊 | 追擊並攻擊敵人 |
| `2` | Charge 衝鋒 | 積極追擊，條件允許時衝刺 |
| `3` | Defend 防禦 | 留在原地，攻擊進入範圍的敵人 |
| `4` | Formation 列陣 | 移動到指定位置列陣 |
| `5` | Follow me 跟隨 | 選定部隊提供此命令時，跟隨玩家 |
| `6` | Dismiss 收隊 | 選定部隊提供此命令時，返回整補 |
| `Q`／<kbd>&#96;</kbd> | Back 返回 | 關閉命令子選單 |

選擇 **Formation 列陣**後，用準星指向地面，檢查預覽，再按 `E`、左鍵或中鍵確認。障礙物或無效位置無法確認；按 `Q` 取消。

## 存檔

Career 自動保存陣營、已任命軍階、軍功、裝備、坐騎、戰鬥技能、部隊、單挑進度、競賽結果與最佳時間、任務檢查點及教學進度；再次進入 Career 就會延續已保存的進度。Campaign 保存各陣營的關卡進度。主選單的訓練場與自訂戰鬥不會推進 Career。

存檔留在目前裝置，**瀏覽器與桌面版各自保存，不會同步**。以新版替換桌面程式會保留存檔；清除瀏覽器網站資料或程式的使用者資料，則會移除對應存檔。
