# SagaBurst 3D Game

[English](./README.md) | **繁體中文**

加入 Viking 與 Roman 的大型戰鬥、指揮部隊、培養自己的軍旅生涯，也能騎著巨鷹飛上天空。**SagaBurst** 是一款使用鍵盤與滑鼠、適合桌上型電腦遊玩的 3D 動作遊戲。

## 開始遊玩

[**直接在瀏覽器玩**](https://andy-ch-bo-an.github.io/SagaBurst-3D-Game/) · [**下載桌面版**](https://github.com/Andy-CH-BO-AN/SagaBurst-3D-Game/releases/latest)

本說明以儲存庫目前版本為準；線上版與桌面發行版可能尚未包含所有玩法。

- **Windows x64：**完整解壓 ZIP 後開啟 `SagaBurst.exe`，請保留解壓後的整個資料夾。
- **macOS Apple Silicon：**解壓 ZIP，將 `SagaBurst.app` 移到「應用程式」，依隨附的[首次開啟說明](./MACOS-FIRST-LAUNCH.txt)操作。程式尚未經 Apple 公證，可能需要到「系統設定 → 隱私權與安全性 → 強制打開」。
- Windows 版未做程式簽署，可能顯示 SmartScreen；確認信任官方下載後，可選「其他資訊 → 仍要執行」。

桌面版包含遊戲資產，可以離線遊玩，不需要安裝開發工具。

**第一次玩？**選 **Career 生涯模式**建立角色，即可跟著新兵操作教學開始。主選單的 **Training Ground 訓練場**可自由練習；**Custom Battle 自訂戰鬥**可自行配置軍隊。

點擊遊戲畫面即可鎖定滑鼠、操作鏡頭。`Esc` 會釋放游標；Career 與訓練場還有暫停選單。

## 遊戲模式

### Training Ground 訓練場

自由練習，不消耗軍功，也不影響 Career 進度。

- 試用武器、盾牌，以及四種坐騎：**戰馬、黑貓、柯基、xongkoro 巨鷹**。
- 對 **0–100 公尺的假人**練習近戰與射擊，查看最近一次命中的傷害。
- 利用標示的射擊點與 **125 公尺衝撞跑道**練習遠程攻擊及騎乘衝鋒。
- 按 `Tab` 開啟裝備；使用 **Refill 補給**補充物資，或 **Reset Training 重置**恢復場地。
- 在 `Esc` 選單切換一般戰士或 **T4 Shadow Warden 遊俠**。兩者都能切換一般近戰武器、遠程武器與盾牌；切換角色會返回起點。

訓練不累積戰鬥 XP。

### Custom Battle 自訂戰鬥

自由配置 Viking vs Roman 戰場。

- 雙方各可設定 **1–200 名 AI 士兵**，混合步兵、弓兵、標槍兵、騎兵與弓騎兵。
- 一般兵種有 **T1 / T2 / T3**，每方還可加入最多 **三名 T4 英雄**；英雄計入設定的 AI 總人數。
- 選擇 **Formation Battle 列陣戰**或 **Scattered Battle 散兵戰**，並以 **Preset 兵種**或 **Squad 小隊**分組下令。
- 選擇玩家陣營、武器、盾牌、角色與坐騎，也能開啟 **Spectator 觀戰**觀看 AI 對戰。玩家角色可選 T1–T3 一般士兵或 T4／T5 英雄，與 AI 軍隊的三名英雄上限分開計算。
- 使用 Squad 分組時，可在開戰前編成最多**八隊、每隊最多 30 人**的小隊。
- 玩家是額外加入的角色，不計入 AI 人數。死亡後可繼續觀戰；按 **REMATCH** 用相同設定再戰。

### Defense Campaign 防守戰役

選擇 **Roman Defense** 或 **Viking Defense**，防守陣營前哨站；**每個陣營各有九關**。

- 各關的一般守軍上限為 **80–90 人**，須遵守該關的 Tier 與騎兵限制。可額外加入最多**一名 T4 英雄**，不占上述名額；玩家也不占守軍名額。攻方有 **100–200 名一般士兵，加兩名 T4 英雄**。
- 出戰前先編成小隊，進場後有 **60 秒部署時間**，倒數結束才開始敵軍進攻。
- 守住營門、圍牆與城牆步道，迎擊敵軍及移動攻城坡道車。進攻開始 **120 秒後**，會派出 **50 名友軍騎兵**，從遠處趕往戰場增援。
- 全殲攻軍即可立即獲勝；若援軍出現前，玩家與原始守軍已全滅，就會鎖定敗北，之後仍可觀戰。
- 勝利後解鎖下一關，Roman 與 Viking 的進度分開保存。

### Career 生涯模式

建立 Roman 或 Viking 角色，沿著 **Recruit 新兵 → Soldier 士兵 → Veteran 老兵 → Captain 隊長 → Commander 指揮官**晉升。

只需選擇陣營，即可借用裝備進入新兵訓練；完成領取 100 軍功後，再到城鎮武器店購買第一把永久武器。靠近功能 NPC 按 `E` 交談，騎乘時也能互動。商店可買賣武器、盾牌與坐騎；按 `Tab` 開啟角色、背包與已解鎖的部隊換裝分頁。

#### 隨軍階成長的教學

新角色先到練習場，依序練習視角與移動、`Tab` 裝備、近戰、盾牌、弓箭、上馬與騎乘下馬。提示位於指北針下方；按 `Esc` 顯示游標後，仍可操作教學的重置、重試與稍後繼續按鈕。完成且一次性 **100 軍功**保存成功後，會自動返回城鎮，再到既有武器店買第一把武器；新角色不配發永久起始武器，借用的裝備與馬留在練習場。可稍後繼續，再找城鎮的**士官長**恢復。舊角色已持有的武器保留。

回城後跟著指標找士官長，購買武器可領一次 **20 軍功**，再與騎兵隊長進行新兵切磋：勝利 **500**、正常失敗 **20 軍功**，不影響正式 1v1 逐階解鎖。之後正常結算兩次正式戰鬥任務，且可用軍功足以買普通馬時，士官長會介紹馬店；首次購馬教學可領一次 **50 軍功**。賽馬入口為**士官長 → 1v1 → Racing／繞城賽馬**。

首次正式接受 **Captain** 任命後，可找士官長進入 **30 名 AI** 的指揮演練，練習選小隊、列陣、防禦、攻擊與衝鋒；再到 **HR Center** 招募私兵，選 **Personal Squad → Follow me**。首次正式接受 **Commander** 任命後，沿指標上指揮塔，練習 **ALL → Defend** 與個別正式小隊列陣。列陣仍應放在塔外合法地面。

教學進度隨角色保存，可稍後繼續或重播；重播不重複發獎。舊角色保留原有進度，可從士官長選擇適用教學。教學演練不計正式任務勝場，不增加永久戰鬥技能，也不消耗正式部隊或私兵。

#### 軍功與任命

透過 Career 戰鬥貢獻與競賽勝利賺取軍功。任命依**本次入伍累積的軍功**核定，花費可用軍功不會讓資格或軍階倒退。達標後仍需找對應 NPC，親自接受任命。

| 軍階 | 所需軍功 | 任命來源 |
| --- | --- | --- |
| Recruit 新兵 | 0 | 初始軍階 |
| Soldier 士兵 | 300 | 騎兵隊長 Cavalry Captain |
| Veteran 老兵 | 900 | 騎兵隊長 Cavalry Captain |
| Captain 隊長 | 5,000 | 騎兵隊長 Cavalry Captain |
| Commander 指揮官 | 20,000 | 城鎮指揮官 Commander |

Commander 解鎖 T5 裝備，接受任命時會獲得陣營對應的 **T5 劍或斧**。

#### 任務與活動

- **接任務：**找**士官長 Sergeant**接取剿匪、巡邏、騎兵清剿、Outpost 防守與救援、守城、老兵戰鬥，以及四門進攻的敵城攻堅。晉升後仍能遊玩先前的任務階級。完成 Soldier 前哨站防守關卡可解鎖救援；救援勝利後解鎖敵城攻堅。
- **單挑：**士官長的 **1v1** 頁面可選兵種，依序挑戰 **T1 到 T5**。每場有五秒準備、30 秒戰鬥時間；擊敗一階才會解鎖該兵種的下一階。T5 由城鎮指揮官出戰，Captain 擔任裁判。
- **戰鬥技能：**培養**單手武器、雙手武器、遠程、騎馬衝撞、格擋**五項技能，每項最高 50 級。
- **野外遭遇：**即使沒有正式任務，城鎮巡邏隊、盜匪、敵對地面部隊與巨鷹巡邏隊也會在城外相遇並交戰。

**Captain I–VI** 任務包含巡邏指揮、騎兵清剿、城門防衛、前線指揮、攻城與**巨鷹空戰 Eagle Battle**。每場可指揮的正式部隊依任務授權而定。巨鷹空戰是 **30 對 30**，招募的私人小隊會額外參戰；玩家需要有一隻可使用的自有 xongkoro。

正式接受 Commander 任命後，**Commander I–V** 頁面提供五項任務：

| 任務 | 目標 |
| --- | --- |
| I · Sky Raid 空襲敵城 | 率領 **50 名 T4 遊俠騎乘 xongkoro** 進攻敵城，擊敗 **100 名不重複的敵城原生人員**。 |
| II · Operation Decapitation 斬首行動 | 與前任 **T5 Commander 及 29 名 T4 騎兵**攻入敵城，擊敗敵方 T5 Commander。 |
| III · Outpost Last Stand 前哨決戰 | 用 **60 秒**部署**四隊、共 120 名步兵**，全殲 **100 名敵方騎兵**。 |
| IV · Bridgehead Battle 橋頭決戰 | 用 **180 秒**在北岸部署**八隊、每隊 25 人，共 200 名步兵**，守住橋梁，迎擊**十二隊、共 300 名騎兵**。 |
| V · Four-Gate Town Defense 四門總攻守城戰 | 用 **180 秒**準備，迎擊 **200 名地面攻軍、八台攻城坡道車與 30 名巨鷹騎射兵**。正式進攻後守住 **15 分鐘**且守方仍有人存活即可獲勝，也能提前全殲 **230 名攻軍**。 |

#### 帶領自己的部隊

- **Captain：**在城鎮指揮 **30 人正式城防指揮隊 Town Command Squad**。
- **Commander：**指揮**八支正式地面小隊**，北、南、東、西四門各有一隊步兵及一隊騎兵。城鎮原生巨鷹巡邏隊與瞭望塔弓兵會自主防守。
- **Personal Squad 私人小隊：**Captain 或 Commander 可在 **HR Center 人力資源中心**招募，最多 **30 人**。可選士兵、T4 Captain 與 T4 遊俠；Commander 還能招募 **T5 Commander**。從持有庫存分配武器、盾牌與坐騎，用 **Follow me 跟隨**出隊，或在城鎮用 **Dismiss 收隊**送回。
- **Civilian Squad 平民小隊：**Commander 在所屬城鎮也能對可用的平民及商人分組下令；Dismiss 讓他們返回原本工作。

正式任務會另外授予指揮權與部隊名單，請以命令 HUD 顯示的編組為準。任務期間可能限制換裝；和平時可找 HR 整補私兵，或找士官長整補可用的城鎮小隊。

#### 繞城坐騎競賽

找**士官長 → 1v1 → 繞城賽馬 Racing**，參加八場對抗城鎮指揮官的競賽。報名時需騎著**自有、存活且可用的地面坐騎**，xongkoro 不能參賽。競賽與地面坐騎都沒有軍階門檻。

跟隨 Captain 到北門，在 **10 秒倒數**結束前留在城門內側的起跑區。起跑後從北門出城，沿城外**東 → 南 → 西**繞行，再由北門入城，依序通過**五個檢查點**。穿越城內抄近路或中途下坐騎，會失去合法完賽資格。玩家每場都能使用 `Shift` 衝刺。

| 賽事 | 對手坐騎 | 對手速度 | 勝利軍功 |
| --- | --- | --- | --- |
| I | 戰馬 | 一般 | 100 |
| II | 柯基 | 一般 | 400 |
| III | 重甲雪豹 | 一般 | 900 |
| IV | 黑貓 | 一般 | 1,600 |
| V | 戰馬 | 衝刺 | 2,500 |
| VI | 柯基 | 衝刺 | 3,600 |
| VII | 重甲雪豹 | 衝刺 | 4,900 |
| VIII | 黑貓 | 衝刺 | 6,400 |

競賽結果與個人最佳合法完賽時間都會保存。舊存檔已接受的賽事保留原名稱與獎勵，新報名使用八場賽程；既有紀錄與最佳時間仍對應原本的坐騎與速度模式。

#### 坐騎與飛行

Captain 或 Commander 可以找城鎮的**巨鷹訓練場主 Eagle Trainer**，以 **10,000 軍功**購買 **xongkoro**，最多持有三隻。在開闊起降區召喚後，就能飛越戰場、用巨鷹攻擊，或在鷹背上使用遠程武器。戰馬、黑貓與柯基也能隨軍階解鎖，在城鎮商店購買。

#### 申請退休

累積 **10 場 Commander 任務勝利**，並至少贏過一次**四門總攻守城戰**後，可找城鎮的**指揮官**選擇**申請退休**。申請前須先完成目前任務或競賽，並讓城鎮處於和平狀態。接受前請閱讀遊戲內的確認說明，之後依畫面引導操作。

### Units & Weapons 兵種與武器

從主選單開啟 **Units & Weapons**，查看兵種特性、戰鬥數值、武器與盾牌資料，再決定裝備配置。

## 操作方式

| 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動；騎乘轉向依坐騎而異 |
| 滑鼠 | 控制視角／巨鷹轉向 |
| `Shift` | 衝刺／飛行加速 |
| `Space` | 徒步或地面坐騎跳躍 |
| 滑鼠左鍵 | 近戰；騎乘 xongkoro 且未瞄準時發動巨鷹攻擊 |
| 按住右鍵 | 舉起已裝備的盾牌，或遠程瞄準 |
| 右鍵 + 按住／放開左鍵 | 拉弓／放箭 |
| 右鍵 + 點擊左鍵 | 投擲 Pilum 標槍 |
| `E` | 交談／互動／拾取裝備／上下坐騎 |
| `Tab` | 角色與背包；訓練場裝備 |
| `I` | 戰鬥與訓練場的另一個背包快捷鍵 |
| 滑鼠滾輪 | 切換武器／盾牌；命令模式下選部隊或命令 |
| `Q` | 切換滾輪換裝／命令模式；關閉命令子選單、取消列陣；關閉 Career 面板 |
| 滑鼠中鍵 | 確認目前選中的部隊或命令 |
| `G` | 提供城門控制的前哨站戰鬥可開關營門 |
| `Esc` | 關閉介面／釋放游標；Career 與訓練場可暫停 |

**觀戰操作：**使用移動鍵與滑鼠，`Space`／`Ctrl` 上升／下降，`Shift` 加速。

### xongkoro 飛行

按 **`W` 起飛**，用**滑鼠轉向**、**`A`／`D` 轉彎**，按住 **`Shift` 加速**。巨鷹飛行時會持續向前，按住 **`S` 減速**，接近開闊地面、降低高度後降落，再安全下鷹。空中也能離開坐騎，但角色會墜落。

未瞄準時按左鍵發動巨鷹攻擊。持有遠程武器時，按住右鍵進入騎手視角，再照一般方式射擊。瞄準可在有限角度內自由轉動；接近角度邊緣時，也會帶動巨鷹轉向。

### 戰鬥提示

- **弓箭：**按住右鍵瞄準、按住左鍵拉弓、放開左鍵射擊；Pilum 是瞄準時點擊左鍵投擲。
- **盾牌：**只有實際命中盾牌的攻擊才會被擋下；側面與背面仍可能打中身體，盾牌也有有限的戰鬥耐久。
- 遠程武器與盾牌不能同時裝備，滾輪切換會自動收起衝突的物品。
- 戰場營地可取得裝備、彈藥與備用戰馬。

## 軍隊命令

按 **`Q`** 將滾輪切到命令模式，用滾輪選擇兵種或小隊，按**滑鼠中鍵**確認，再用同樣方式選命令並下令。命令子選單或列陣中按 `Q` 可關閉／取消；在子選單外按 `Q` 則切換命令與武器選擇。**反引號**（<kbd>&#96;</kbd>）可直接開啟 **ALL 全軍**命令，也能關閉已開啟的命令子選單。

也能用鍵盤直接選目標。在 **Preset 兵種分組**下：

| 按鍵 | Viking | Roman |
| --- | --- | --- |
| `1` | 資深戰士 Veteran | 重裝步兵 Heavy Infantry |
| `2` | 槍兵 | 槍兵 |
| `3` | 弓兵 | 弓兵 |
| `4` | 刀騎兵 | 標槍兵 |
| `5` | 槍騎兵 | 刀騎兵 |
| `6` | 弓騎兵 | 槍騎兵 |
| `7` | — | 弓騎兵 |
| <kbd>&#96;</kbd> | ALL 全軍 | ALL 全軍 |

在 **Squad 小隊分組**下，`1`–`8` 選擇對應的正式小隊。Commander 在所屬城鎮時，`1`／`2` 為北門步兵／騎兵，`3`／`4` 為南門，`5`／`6` 為東門，`7`／`8` 為西門。Career 用 `9` 選 **Personal Squad 私人小隊**，`0` 選可用的 **Civilian Squad 平民小隊**；任務中的正式編組則依任務而異。命令只適用於授權給你的部隊，附近友軍不會自動成為你的指揮對象。

選好目標後：

| 按鍵 | 命令 | 效果 |
| --- | --- | --- |
| `1` | Attack 攻擊 | 追擊並攻擊敵人 |
| `2` | Charge 衝鋒 | 積極追擊，條件允許時衝刺 |
| `3` | Defend 防禦 | 留在原地，攻擊進入範圍的敵人 |
| `4` | Formation 列陣 | 移動到指定位置列陣 |
| `5` | Follow me 跟隨 | 選定部隊提供此命令時，跟隨玩家 |
| `6` | Dismiss 收隊 | 選定部隊提供此命令時，返回整補 |
| `Q`／<kbd>&#96;</kbd> | Back 返回 | 關閉命令子選單 |

選擇 **Formation 列陣**後，用準星指向地面，檢查預覽，再按 `E`、左鍵或中鍵確認。障礙物或無效位置無法確認；按 `Q` 取消。

## 存檔

Career 自動保存陣營、已任命軍階、軍功、裝備、坐騎、戰鬥技能、部隊、單挑進度、競賽結果與最佳時間、任務檢查點及教學進度；再次進入 Career 就會延續已保存的進度。Campaign 保存各陣營的關卡進度。主選單的自由訓練場與一般自訂戰鬥不會推進 Career。

存檔留在目前裝置，**瀏覽器與桌面版各自保存，不會同步**。以新版替換桌面程式會保留存檔；清除瀏覽器網站資料或程式的使用者資料，則會移除對應存檔。
