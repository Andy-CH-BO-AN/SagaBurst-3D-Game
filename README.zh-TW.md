# SagaBurst 3D Game

[English](./README.md) | **繁體中文**

**SagaBurst** 是一款可直接在瀏覽器遊玩的 3D 動作遊戲，玩家可以親自加入 Viking 與 Roman 的大型戰鬥，也能指揮自己的部隊。

這份 README 只保留玩家需要知道的內容：**怎麼開始、有哪些模式、怎麼操作、怎麼下軍隊命令**。

## 🚀 開始遊玩

SagaBurst 適合使用 **鍵盤與滑鼠的桌上型電腦**。

### 線上遊玩 Play Online

[直接在瀏覽器玩 SagaBurst](https://andy-ch-bo-an.github.io/SagaBurst-3D-Game/)，不需要安裝。正式網站會在第一次 `prod` 部署後開放。

### 下載 Download

[到 GitHub Releases 下載 SagaBurst](https://github.com/Andy-CH-BO-AN/SagaBurst-3D-Game/releases)。

- **Windows x64：**解壓 ZIP 後雙擊 `SagaBurst.exe`，請保留解壓後整個資料夾。
- **macOS Apple Silicon：**解壓 ZIP，把 `SagaBurst.app` 移到「應用程式」後開啟。

第一版 v1.0.0 的下載會在正式發布後出現。目前未做程式簽署；macOS 首次可能需要右鍵 → 開啟，或在嘗試開啟後，到「系統設定 → 隱私權與安全性 → 強制打開」。Windows 可能顯示 Microsoft Defender SmartScreen；確認信任來源後，可選「其他資訊 → 仍要執行」。

Career 與 Campaign 使用本機存檔。瀏覽器和桌面版各自保存，v1 不同步；清除瀏覽器網站資料或桌面版使用者資料會移除存檔。

進入戰鬥後，點擊遊戲畫面鎖定滑鼠；按 `Esc` 釋放游標，再點擊畫面恢復鏡頭操作。

### 開發 Development

使用 Node.js 22 或更新版本。新功能 PR 請以 `dev` 為目標。

```bash
git clone --branch dev https://github.com/Andy-CH-BO-AN/SagaBurst-3D-Game.git
cd SagaBurst-3D-Game
npm ci
npm run dev
```

開啟 Vite 顯示的本機網址。以 `npm test` 和 `npm run build` 驗證修改；`npm run desktop` 可在本機開啟桌面版。維護者請參閱[發版指南](./docs/RELEASING.md)。

## 🎮 遊戲模式

### ⚔️ Custom Battle 自訂戰鬥

自由配置 Viking vs Roman 戰場。

- 雙方各可配置 **1–200 名 AI 士兵**。
- 可混合步兵、遠程兵、騎兵與弓騎兵。
- 可選 **Formation Battle 列陣戰** 或 **Scattered Battle 散兵戰**。
- 可設定玩家陣營、武器、盾牌，以及騎馬或徒步開場。
- 可以親自參戰，也可以開啟 **Spectator 觀戰模式**只看 AI 對戰。
- 出戰前可以選擇以**兵種**或**小隊**作為軍隊命令分組。

Player 是額外加入所選陣營的角色，不計入雙方設定的 AI 人數。

### 🏰 Defense Campaign 防守戰役

選擇 **Roman Defense** 或 **Viking Defense**，配置守軍並防守陣營前哨站。

- 每個陣營目前各有 **9 關**。
- 勝利後依序解鎖下一關。
- Roman / Viking 通關進度分開保存。
- 每一關的守軍配置與敵軍攻勢都不同。
- 若選擇小隊分組，可在出戰前先完成守軍的小隊編成。

### 🏘️ Career 生涯模式

建立一名持續成長的 Roman 或 Viking 角色，從新兵一路晉升成能帶領自己部隊的軍官。

- 選擇陣營與起始武器，探索有**城牆、四座城門、步兵／騎兵訓練區、商店、兵營、城門守軍與騎兵巡邏隊**的 Career 城鎮。
- 面向功能 NPC 按 `E` 交談，購買與管理武器、裝備、盾牌與坐騎，並透過角色／背包介面保存自己的裝備配置。
- 依軍階接取剿匪、巡邏、Outpost、防守、騎兵任務、Veteran 任務，以及**四門同時進攻的 Enemy Town Assault**；升階後仍可遊玩先前解鎖的任務。
- 城外世界不是靜態背景：城鎮巡邏隊、Bandit 與敵對勢力會在野外自然遭遇並交戰。
- Career 有五種持續成長的戰鬥技能：**單手武器、雙手武器、遠程、騎馬衝撞、格擋**。每項最高 50 級，回城或切換任務都會保留進度。
- 升到 **Captain** 或 **Commander** 後，可以前往 **HR Center 人力資源中心**建立自己的 **Personal Squad 私人小隊**，最多 30 人。可以招募成員、調整裝備，用 **Follow me** 讓他們出隊跟隨，也能用 **Dismiss** 讓他們返回 HR Center 整補。
- Personal Squad 可以跟著玩家進入 Career 任務，並透過戰鬥表現貢獻指揮軍功，同時持續保留為玩家自己的部隊。
- 透過戰鬥與任務累積軍功，解鎖更高軍階與裝備階級；Career 會保存陣營、軍階、軍功、裝備、坐騎、技能與 Personal Squad 進度。

### 🐈 英雄坐騎試騎

從主選單進入英雄坐騎試騎，可以在空場直接體驗 **黑貓**、**柯基**等特殊坐騎。

試騎沿用一般的移動、衝刺、跳躍與上下坐騎操作；在 Career 中達成對應解鎖條件後，也可以正式購買這些特殊坐騎。

## 🕹️ 操作方式

| 按鍵 / 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動 |
| 滑鼠 | 控制視角 |
| `Shift` | 衝刺 |
| `Space` | 跳躍 |
| 滑鼠左鍵 | 未瞄準時進行近戰攻擊 |
| 按住滑鼠右鍵 | 舉盾，或使用遠程武器瞄準 |
| 按住右鍵 + 按住 / 放開左鍵 | 弓箭拉弓 / 放箭 |
| 按住右鍵 + 點擊左鍵 | 投擲 Pilum 標槍 |
| `E` | 互動 / 拾取裝備 / 上馬 / 下馬 |
| `Tab` 或 `I` | 角色與背包 |
| 滑鼠滾輪 | 切換持有的武器／盾牌；命令模式下選擇部隊或命令 |
| `Q` | 進入命令滾輪模式 / 返回上一層命令 |
| 滑鼠中鍵 | 確認目前選中的部隊或命令 |
| `Esc` | 關閉 UI / 解除滑鼠鎖定 |

### 遠程攻擊

- **弓箭：**按住右鍵瞄準，按住左鍵拉弓，放開左鍵射擊。
- **Pilum 標槍：**按住右鍵瞄準，再點擊左鍵投擲。
- 按住右鍵會進入第一人稱遠程瞄準。弓箭只要持續按住右鍵就會維持第一人稱；Pilum 離手後會回到第三人稱。

### 盾牌戰鬥

- 裝備盾牌時，按住滑鼠右鍵即可舉盾。
- 只有攻擊或投射物**實際命中舉起的盾牌**時才會被格擋；從側面、背面或其他位置打到身體仍會正常受傷。
- 盾牌在戰鬥中有有限的衝擊耐久，較強的斧頭攻擊會消耗更多耐久。
- **格擋 Blocking** 是 Career 的持續成長技能，成功格擋會提升相關能力。

## 📯 Army Command 軍隊命令

出戰前可以選擇以兵種或小隊作為命令分組。進入戰場後，可以命令單一兵種、單一小隊或全軍。

### 滑鼠滾輪操作

1. 按 `Q` 進入命令模式。
2. 用滑鼠滾輪選擇兵種、小隊或 **ALL 全軍**。
3. 按滑鼠中鍵確認。
4. 用滾輪選擇 **攻擊、衝鋒、防禦、列陣**。
5. 再按滑鼠中鍵下令。
6. 按 `Q` 返回上一層，或離開命令選擇。

選好指揮目標後：

| 按鍵 | 命令 | 效果 |
| --- | --- | --- |
| `1` | **攻擊 Attack** | 主動追擊並正常攻擊敵人 |
| `2` | **衝鋒 Charge** | 積極追擊敵人，條件允許時衝刺 |
| `3` | **防禦 Defend** | 留在目前位置，攻擊進入有效範圍的敵人 |
| `4` | **列陣 Formation** | 將部隊移動到指定位置重新列陣 |
| `Q` | **上一頁 Back** | 返回上一層命令選單 |

| 按鍵 | 命令 | 效果 |
| --- | --- | --- |
| `5` | **Follow me · 跟隨** | 讓已部署的私人小隊重新集合並跟隨玩家 |
| `6` | **Dismiss · 收隊** | 讓私人小隊返回 HR Center 並進行整補 |

### 列陣操作

選擇 **Formation 列陣**後：

1. 用畫面中央準星指向想要列陣的位置。
2. 查看即時陣形 Preview。
3. 按 `E`、滑鼠左鍵或滑鼠中鍵確認。
4. 按 `Q` 取消並返回命令選單。

障礙物或其他無效位置無法確認列陣。

## ☠️ 戰鬥與進度

- **Custom Battle** 中玩家死亡後會直接切換成觀戰模式，剩餘 AI 會繼續戰鬥。
- 可使用 **REMATCH** 以相同設定重新開始 Custom Battle。
- Custom Battle 的一般兵種目前使用 **T1 / T2 / T3** 裝備階級。
- 戰場營地可取得裝備、彈藥與備用戰馬。
- Defense Campaign 的 Roman / Viking 進度會分開保存。
- Career 會保留自己的陣營、軍階、軍功、裝備、坐騎、戰鬥技能與 Personal Squad 進度。

遠程武器與盾牌不能同時裝備，透過滾輪切換時會自動收起衝突裝備；Career 城鎮與任務皆使用相同的裝備切換規則。
