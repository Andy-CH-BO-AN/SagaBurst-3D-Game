# SagaBurst 3D Game

[English](./README.md) | **繁體中文**

這是一個使用 **Three.js**、**TypeScript** 與 **Vite** 製作、可直接在瀏覽器中遊玩的 3D 動作 RPG 原型。

目前遊戲內標題為 **Warriors: Dedicate Your Heart!**。你可以在戰場中探索、使用近戰武器或弓箭與敵人戰鬥、拾取裝備、騎乘戰馬，並透過戰鬥培養角色能力。

## 🎮 怎麼玩

### 1. 安裝與啟動

你需要先安裝 **Node.js** 與 **npm**。

```bash
git clone https://github.com/Andy-CH-BO-AN/SagaBurst-3D-Game.git
cd SagaBurst-3D-Game
npm ci
npm run dev
```

接著用瀏覽器開啟 Vite 顯示的本機網址，並點擊畫面上的 **CLICK TO START**，鎖定滑鼠後就可以開始遊戲。

> 遊戲目前以桌面版鍵盤 + 滑鼠操作為主。

## 🕹️ 操作方式

| 按鍵 / 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動 |
| 滑鼠 | 視角 / 鏡頭控制 |
| `Shift` | 衝刺 |
| `Space` | 跳躍 |
| 滑鼠左鍵 | 近戰攻擊 |
| 按住滑鼠右鍵 + 滑鼠左鍵 | 瞄準 / 使用弓箭射擊 |
| `E` | 拾取裝備 / 騎馬 / 下馬 |
| `Tab` 或 `I` | 開啟角色與背包介面 |
| `0` | 開啟遊戲選單 |
| `Esc` | 關閉選單 / 背包，或解除滑鼠鎖定 |

## ⚔️ 遊戲內容

- **近戰戰鬥** — 使用劍與其他近戰武器與敵人戰鬥。
- **弓箭戰鬥** — 按住右鍵進入瞄準，再使用左鍵拉弓與射擊。
- **裝備拾取** — 探索地圖，在掉落裝備附近按 `E` 即可拾取。
- **武器成長** — 遊戲中有不同等級的近戰武器、弓與盾牌。
- **箭矢補給** — 箭袋快空時，可以在地圖上拾取箭矢補給。
- **戰馬** — 靠近馬匹後按 `E` 騎乘，再按一次 `E` 即可下馬。
- **騎乘移動** — 騎馬時仍使用相同的移動方式，也可以衝刺與跳躍。
- **角色成長** — 戰鬥會推進 RPG 技能與角色成長系統，可在角色介面查看。
- **存檔 / 讀檔** — 按 `0` 或使用左上角選單儲存與載入遊戲進度。

## 🏹 第一次進遊戲可以這樣玩

1. 點擊畫面開始遊戲並鎖定滑鼠。
2. 使用 `WASD` 移動，滑鼠控制視角。
3. 找到敵人後使用滑鼠左鍵進行近戰攻擊。
4. 想使用遠程攻擊時，按住滑鼠右鍵瞄準，再用左鍵射箭。
5. 地圖上可以找到武器、盾牌、弓與箭矢補給，靠近後按 `E` 拾取。
6. 靠近馬匹後按 `E` 即可騎乘。
7. 按 `Tab` 或 `I` 查看角色、技能、背包與目前裝備。
8. 離開遊戲前，可以用 `0` 開啟選單並儲存進度。

## 🧰 開發指令

```bash
# 啟動開發伺服器
npm run dev

# 執行測試
npm test

# TypeScript 檢查並建立 production bundle
npm run build

# 預覽 production build
npm run preview
```
