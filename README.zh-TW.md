# SagaBurst 3D Game

[English](./README.md) | **繁體中文**

**SagaBurst** 是一款可直接在瀏覽器遊玩的 3D 動作遊戲，玩家可以親自加入 Viking 與 Roman 的大型戰鬥，也能指揮自己的部隊。

這份 README 只保留玩家需要知道的內容：**怎麼開始、有哪些模式、怎麼操作、怎麼下軍隊命令**。

## 🚀 開始遊玩

SagaBurst 目前以 **桌面瀏覽器 + 鍵盤滑鼠** 為主。

```bash
git clone https://github.com/Andy-CH-BO-AN/SagaBurst-3D-Game.git
cd SagaBurst-3D-Game
npm ci
npm run dev
```

接著開啟 Vite 顯示的本機網址。

進入戰鬥後點擊遊戲畫面即可鎖定滑鼠控制鏡頭；按 `Esc` 可釋放游標，再點擊遊戲畫面即可繼續操作。

## 🎮 遊戲模式

### ⚔️ Custom Battle 自訂戰鬥

自由配置 Viking vs Roman 戰場。

- 雙方各可配置 **1–200 名 AI 士兵**。
- 可混合步兵、遠程兵、騎兵與弓騎兵。
- 可選 **Formation Battle 列陣戰** 或 **Scattered Battle 散兵戰**。
- 可設定玩家陣營、武器、盾牌，以及騎馬或徒步開場。
- 可以親自參戰，也可以開啟 **Spectator 觀戰模式**只看 AI 對戰。
- 出戰前可以選擇以**兵種**或**小隊**作為軍隊命令分組。

Player 是額外加入所選陣營的角色，不計入雙方設定的 AI 人數。

### 🏰 Defense Campaign 防守戰役

選擇 **Roman Defense** 或 **Viking Defense**，配置守軍並防守陣營前哨站。

- 每個陣營目前各有 **9 關**。
- 勝利後依序解鎖下一關。
- Roman / Viking 通關進度分開保存。
- 每一關的守軍配置與敵軍攻勢都不同。
- 若選擇小隊分組，可在出戰前先完成守軍的小隊編成。

### 🏘️ Career 生涯模式

建立一名持續成長的 Roman 或 Viking 角色。

- 選擇陣營與起始武器。
- 探索自己的陣營小鎮。
- 面向功能 NPC 按 `E` 交談。
- 透過角色 / 背包介面管理已擁有的裝備。
- **騎兵清剿 Cavalry Sweep：**擁有目前可使用的坐騎即可接取，Recruit 也能玩。加入含玩家共 60 人的騎兵隊，跟隨 Captain／Maki，在 60m 一起衝入 40 名 Bandit 集群，練習騎乘、衝鋒與坐騎撞擊。玩家死亡後轉為 Observer；Bandit 全滅即勝利。
- **進攻敵方家園：**完成 Outpost I–III，再於 Outpost Relief · 騎兵救援獲勝後解鎖。加入 90 人、三支小隊的遠征軍。等待 10 秒倒數後進攻，擊敗 63 名軍事守軍即可勝利，不必殺光平民。戰爭中的平民會先撤退、遇到近敵就反擊；玩家只操作自己，死亡後可觀戰到戰鬥結束。
- 與士官長交談，可接取已解鎖的剿匪、巡邏、Town Defense 或 Enemy Town Assault 任務，也能補充箭矢與取得出戰指引。士官長在 Town Defense 中是 T3 徒步守軍。
- Soldier 以上可向士官長接取 Outpost Duty I–III；帶著已擁有裝備加入 AI 駐軍防守，獲勝依序解鎖下一關。不需要坐騎，沒有援軍，也無法下全軍命令或操作營門。戰後結算 Career 戰鬥軍功並返回自己的小鎮，進度與正式 Campaign 分開。
- 晉升後仍可遊玩先前已解鎖的低階任務。
- 先與隊長集合，跟著指引箭頭和隊伍行軍，獲勝後再返回小鎮。
- Bandit 平時會在營地巡邏，發現接近的威脅或遭到攻擊才會反擊。
- 親自造成傷害與擊殺，才能獲得任務軍功。
- T1–T3 戰馬需逐階購買；按 `Tab` 後可在「坐騎」區騎乘、切換或遣返已擁有坐騎。
- 藉任務累積晉升資格，再請隊長任命下一軍階。已任命為 Captain 或 Commander 時，玩家會使用所屬陣營的 T4 英雄。

### 🐈 英雄坐騎試騎

從主選單進入英雄坐騎試騎，可以在空場直接體驗 **黑貓**、**柯基**等特殊坐騎。

試騎沿用一般的移動、衝刺、跳躍與上下坐騎操作。

## 🕹️ 操作方式

| 按鍵 / 操作 | 功能 |
| --- | --- |
| `W` `A` `S` `D` | 移動 |
| 滑鼠 | 控制視角 |
| `Shift` | 衝刺 |
| `Space` | 裝備盾牌時按住舉盾；沒盾牌時跳躍 |
| 滑鼠左鍵 | 未瞄準時進行近戰攻擊 |
| 按住右鍵 + 按住 / 放開左鍵 | 弓箭瞄準 / 拉弓 / 放箭 |
| 按住右鍵 + 點擊左鍵 | 瞄準 / 投擲 Pilum 標槍 |
| `E` | 互動 / 拾取裝備 / 上馬 / 下馬 |
| `Tab` 或 `I` | 角色與背包 |
| 滑鼠滾輪 | 預設切換持有的近戰武器；命令模式下選擇部隊或命令 |
| `Q` | 進入命令滾輪模式 / 返回上一層命令 |
| 滑鼠中鍵 | 確認目前選中的部隊或命令 |
| `Esc` | 關閉 UI / 解除滑鼠鎖定 |

### 遠程攻擊

- **弓箭：**按住右鍵瞄準，按住左鍵拉弓，放開左鍵射擊。
- **Pilum 標槍：**按住右鍵瞄準，再點擊左鍵投擲。
- 按住右鍵會進入第一人稱遠程瞄準。弓箭只要持續按住右鍵就會維持第一人稱；Pilum 離手後會回到第三人稱。

## 📯 Army Command 軍隊命令

出戰前可以選擇以兵種或小隊作為命令分組。進入戰場後，可以命令單一兵種、單一小隊或全軍。

### 滑鼠滾輪操作

1. 按 `Q` 進入命令模式。
2. 用滑鼠滾輪選擇兵種、小隊或 **ALL 全軍**。
3. 按滑鼠中鍵確認。
4. 用滾輪選擇 **攻擊、衝鋒、防禦、列陣**。
5. 再按滑鼠中鍵下令。
6. 按 `Q` 返回上一層，或離開命令選擇。

選好指揮目標後：

| 按鍵 | 命令 | 效果 |
| --- | --- | --- |
| `1` | **攻擊 Attack** | 主動追擊並正常攻擊敵人 |
| `2` | **衝鋒 Charge** | 積極追擊敵人，條件允許時衝刺 |
| `3` | **防禦 Defend** | 留在目前位置，攻擊進入有效範圍的敵人 |
| `4` | **列陣 Formation** | 將部隊移動到指定位置重新列陣 |
| `Q` | **上一頁 Back** | 返回上一層命令選單 |

### 列陣操作

選擇 **Formation 列陣**後：

1. 用畫面中央準星指向想要列陣的位置。
2. 查看即時陣形 Preview。
3. 按 `E`、滑鼠左鍵或滑鼠中鍵確認。
4. 按 `Q` 取消並返回命令選單。

障礙物或其他無效位置無法確認列陣。

## ☠️ 戰鬥與進度

- **Custom Battle** 中玩家死亡後會直接切換成觀戰模式，剩餘 AI 會繼續戰鬥。
- 可使用 **REMATCH** 以相同設定重新開始 Custom Battle。
- Custom Battle 的一般兵種目前使用 **T1 / T2 / T3** 裝備階級。
- 戰場營地可取得裝備、彈藥與備用戰馬。
- Defense Campaign 的 Roman / Viking 進度會分開保存。
- Career 會保留自己的陣營、軍階、軍功與已擁有裝備進度。
