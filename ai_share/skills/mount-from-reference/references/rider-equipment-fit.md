# 騎士、鞍具與武器的貼合

在建立騎姿、修改鞍具／座高，或處理持械穿模時使用。方法適用於不同體寬、頸高、耳／角輪廓與步態的坐騎；不提供通用骨盆偏移、關節角度或武器清空高度。

## 先量接觸關係，再調姿勢

| 量測對象 | 必須分清的關係 |
| --- | --- |
| 座面 | 鞍的承重區域、前後鞍橋及側翼；不能以整個鞍的包圍盒頂端當座面 |
| 臀部與骨盆 | 臀部是接觸面，骨盆骨／socket 是關節定位點，通常不重合 |
| 騎士下肢 | 大腿外展後的體積、膝與靴子，不能只看骨線是否位於坐騎外 |
| 騎士服裝 | 裙甲、衣襬與披風另查；整個網格最低點可能是垂掛衣物，不是承重臀部 |
| 掌心與武器 | 掌內握點、模型握點、柄尾、有效柄長、刃寬／厚度；握點正確不代表武器整體清空 |
| 坐騎障礙 | 當前與活動極值下的背、頸、頭、耳／角及護具，而非一個固定身體包圍盒 |

量測採實際載入的騎士、服裝與 posed mesh。蒙皮模型先更新動畫、世界矩陣及 skeleton，再讀變形後頂點；不要以 bind pose 或僅骨骼位置宣稱皮膚無相交。診斷中記下局部座標、單位、根節點、裝備、LOD 與動畫時刻，避免比較不同狀態的數字。

在鞍座座標中，把選定臀部接觸區域貼到座面，得到對應的骨盆位置／朝向；必要時建立獨立 rider-pelvis socket，跟隨承載座面的節點。差值來自當前騎士與姿勢，不從另一動物複製，也不是抬高多少都可的 clearance 參數。若騎士上身保持直立以平衡坐騎俯仰，須驗證這個姿態策略仍維持臀部接觸，不能只檢查位置 socket。

## 按依賴順序修正

1. **座面與臀部**：確認接觸區域與骨盆差值，排除鞍橋頂到腰部、臀部浮空或陷入。座高改變後，馬鐙與持械相對位置也要重查。
2. **下肢與鞍側**：調整符合體型的髖膝姿勢和鞍腰／側翼輪廓，再對靴子與馬鐙。不要為了腿部清空破壞已量測的座面接觸。
3. **手臂與握點**：先沿用當前動作和已校準掛點，觀察手／武器是否落在展開的大腿內。必要時調肩、肘、腕；固定武器相對掌心的握持關係，不把武器平移出手，也不為閃過坐騎改攻擊判定或時間。
4. **活動路徑**：待機清空後，檢查預備、出擊、中段、回收以及取消／換裝／下馬。待機的抬臂修正不能無條件疊到整段攻擊；修正需隨合適的動作階段進出，重播不能累加，離開該騎姿後恢復。

優先修正錯誤的掛點、模型軸向或基礎姿勢，再決定是否需要體型相關的姿勢差異。只有特定組合需要的修正應留在該組合，不把一次性的角度與階段比例提升為所有坐騎共用常數；也不必為單次修正先建立整套碰撞避讓系統。

## 讓動作交叉成為驗收的一部分

從本輪已支援／要求的裝備選代表，不擅自新增武器或要求所有坐騎通過所有配裝：長柄優先查柄尾與前向通道，寬刃查整片刃面，弓查弓臂／弦／拉弓手，盾查左臂與另一武器的互相干涉。

- 每個相關裝備先看待機和完整動作，再挑坐騎最容易壓縮間距的姿勢一起驗：例如高頸抬頭時前刺、外張角附近揮擊、寬背上持長柄，以及跳躍抬頭時回收武器。依幾何與活動範圍選擇，不只按物種名稱套表。
- 預覽至少能看持械側、另一側和上方，並以固定視角比較修正前後。藏在遠側或被頭／盾擋住的武器不能視為通過。
- 依現有架構重用正式載入器、騎姿、裝備與動畫求值；臨時診斷工具放 ignored `output/`，用選項切換組合與固定時刻，不另外複製一套「看起來正確」的姿勢。新增長期預覽控制只限本輪檢視所需。
- 局部驗證後在實際入口重新載入實例，檢查與使用者看到的結果一致。若修正進入共享騎士流程，再用相關 Player／NPC 路徑或契約測試驗證，不只修 studio 的手工位置。

## 相交檢查的範圍與證據

| 方法 | 能提供的證據與限制 |
| --- | --- |
| 固定視角、近景與極值截圖 | 能查解剖、接觸與外觀；少數截圖可能漏掉快速中段，不能代表全程 |
| 包圍盒、骨線或腿部 capsule | 適合找可疑區域和回歸篩查；不能證明實際皮膚／甲片沒有相交 |
| 柄中心線 raycast | 能定位柄穿入表面的時刻；會漏掉柄厚、柄尾與刀刃，也要注意從物體內出發、單面剔除與隱藏網格 |
| 多條偏移線、刃面邊界／表面取樣或體積檢查 | 依缺陷補足武器厚度與刃寬；離散取樣仍需在高速、狹窄或即將接觸的區間加密 |

先對動作全程分段取樣，再在接近或發生相交處找首個失敗時刻、接觸物件與最小間距。不要只修一個峰值角度；動作混合、回收或坐騎極值可能是另一個更差狀態。檢查容許間距應相對實際尺度、表面厚度與動畫變形訂定，不以某次公尺數或固定幀數當通則。

每次修正保留：原缺陷重現、修改後相同時刻、完整動作與恢復、受影響的相鄰裝備／動作，以及量測使用的方法與覆蓋範圍。證據放 `output/`；只將必要的行為不變量寫入長期測試，例如掌內握點、接點變換、單次命中／完成、取消與下馬還原。不要用預期角度數值相等冒充穿模測試。

## 何時重查、何時交付

局部迭代先跑能重現缺陷的量測與回歸；收斂後完成專案要求的完整測試及建置。保留同一診斷場景切換組合，避免每個問題重建工具；只有後續改動影響結論時才重跑已通過的範圍。

- 座高、展髖或鞍寬改變：重查腳／鐙與手／武器，不能只更新座高測試。
- 頸、頭、耳／角或頭甲改變：重查武器經過的通道及相關坐騎動作。
- 武器或手臂姿勢改變：重查另一裝備、盾牌、攻擊中段與恢復；換盾不能把武器換回預設。
- 動畫、共享掛點或載入流程改變：重查還原及相關既有坐騎分支；純文件修改不需要重跑遊戲。

交付說明「檢查了哪些組合，使用哪些證據，還有哪些未覆蓋」，不要把取樣零相交、測試通過或某個好看的角度寫成全面無穿模。留下使用者最後指定的可見配裝與可操作預覽；檢查的是最後修改後的實例，不是修改前截圖。
