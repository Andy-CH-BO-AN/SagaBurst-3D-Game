# 生涯：存檔、軍功與成長

範圍：Career 存檔與提交、教學、劇情事件、軍功、商店、退休與賽馬。索引與共通規則見 [ARCHITECTURE.md](../ARCHITECTURE.md)。

Career 教學由 `CareerTutorialState` 擁有角色識別、步驟、交易／正式任務收據與固定一次性獎勵；`CareerTutorial` 載入最新同角色存檔並在保存成功後發布。新角色的 writer 保存完整教學識別與狀態；載入不推導歷史教學。`CareerTownEntry`／`main` 只以持久化 session 啟動 `CareerTutorialLaunch`，自由訓練與一般自訂戰鬥不取得此能力。`CareerTutorialScene` 接收 Game 的實際操作／有效命中及 `ArmyCommandController.onAccepted`；新兵與隊長演練完成並保存後自動沿同角色交易返回 Town，拒絕寫入時保留現場供重試；新兵坐騎段須先實際騎上訓練場黑貓、再騎上指定普通馬，並以騎該馬對 0m 假人的 `mount-impact` 有效傷害事件完成。提示跟隨既有指北針下緣，暫停時保留可操作的教學按鈕並停止判定。演練只保留教學進度，隔離正式任務、技能與部隊資源。`TownTutorialController` 重用 MissionGuide、現有商店、HR 與指揮授權；已開始而延後的階段在 HUD 指回士官長（或 HR），士官長直接提供「繼續上次教學」並保留「查看正式任務與其他服務」，從未開始而延後的階段維持自選；新兵切磋沿用 Duel 並以角色識別標記走獨立獎勵結算，不改正式逐階解鎖。Captain／Commander 教學隨正式任命交易保存，不以軍功門檻自行啟動。

Career 城鎮劇情事件（`CareerStoryEvents`／`CareerStoryGuidance`／`TownStoryController`）獨立於新兵教學，可延後且不阻擋任務、商店或 NPC 服務。`CareerProfile.careerStory` 以事件是否存在區分尚未觸發（無）、`pending`（待接受）、`active`（已接受，保存活動 ID）與 `settled`（已結算；有 `outcome`／`merit` 才是實際領過獎勵）。觸發只在既有 owner 的同一交易內寫入：`purchaseCareerContent` 的首次普通 `horse` 購買（多匹、賣掉再買、其他坐騎、召喚／借馬皆不觸發；`hadHorse` 含舊教學收據）開 `commander-circuit-race`，`recordCareerMissionCompletion`（正式任務勝利的唯一計數點，含 Outpost 勝利）在本次生涯尚無正式勝利時開 `veteran-squad-spar`；教學的 `settledMissionIds` 不是勝利收據。兩個活動都在正式接受時以同一次保存綁定來源 ID：賽馬為 `CareerRaceSession.story`（僅 `race-1`，指揮官在競速時沿用原生衝刺，經 `CareerRaceController.accept(..., { story: true })`，需騎乘自有普通戰馬），競技場為 T1 `arena-squad-trial` 任務的 `storyEventId`（`acceptArenaStoryTrial`，預設依陣營進場）。結算沿原 owner：`raceRecordProfile` 與 `claimCareerMission` 只在事件 `active` 且 `sourceId` 相符時以固定軍功（賽馬勝 500／敗 29，試煉勝 1,000／敗 100）取代該場一般獎勵並標記 `settled`；賽馬平手釋放回 `pending`；對手部署失敗且尚無賽果時可從暫停選單取消，保存成功才釋放賽事並將邀請退回 `pending`，不新增賽果或軍功；不符者回到一般獎勵。載入時 `parseCareerStoryState`：只接受現行事件狀態；缺少單一事件表示尚未觸發，整份狀態或已存在的事件損壞即拒讀，不由目前軍功、持有物或完成任務重建收據；`active` 但活動已不存在的邀請回到 `pending`，避免取消後無法重新接受。引導由 `selectStoryGuidance` 從最新 profile 一次只選一個目標（待接話劇情 → `canAppointCareerRank`／`t4ClassOffer`／`careerClassOffer` 的任命 → `XONGKORO_PRODUCT.price` 的首隻巨鷹），進行中任務／賽事／退休／敵對時整體隱藏，目標 NPC 不可用時暫停而不改指他人；「晚點再來」只在該 scene 內讓出箭頭，不關閉邀請；由劇情進入任務板後，同次瀏覽的分頁與補箭保留原服務入口，不重開邀請。巨鷹開場台詞以 `eagleIntroSeen` 永久只播一次，`eaglePurchased` 讓售出後不重開。`TownTutorialController.occupiesGuidance()` 決定教學是否佔用箭頭與 NPC 對話：已接受且要求操作的階段優先；等待兩次實戰／軍功的被動提示與已延後階段的提醒讓位給劇情。

- `CareerProfileStore` 使用 `sagaburst_career_v2`（profile version 2），與 RPG／Campaign 存檔隔離。`loadChecked` 區分無存檔與損壞／不支援資料；載入失敗不得覆寫。
- `TownProfileCommit` 集中 Town 候選資料與現場 checkpoint 的優先序，以及保存成功後的發布、兵權交接與返城恢復。呼叫端以普通交易、平民命令、落地返回或任務返回目的地表達變更；完成任務的居民／重建資料由此模組準備，不再由結算端配合覆蓋旗標。`TownScene` 只接入既有資料擁有者與效果；保存拒絕不發布、不交接，返城期間重入保存仍保留恢復權，普通保存／讀檔不整補。
- `CareerProfile` 分開 lifetime `totalMerit`、可花費 `availableMerit` 與任命 `rank`。晉升按 enlistment baseline 計算資格，必須明確任命；領獎不自動升階。獎勵以已領 battle／mission ID 保持冪等。
- `CareerShopCatalog` 是武器／盾牌／坐騎價格與品質 Tier 的可信目錄。`purchaseCareerContent` 核對 ID、分類、價格、Tier 及數量後，允許所有軍階購買正常商品；巨鷹訓練服務保留原軍階與三隻上限。正常商品的裝備與地面坐騎騎乘也不再限制軍階，Tier 仍表示品質；NPC 配發保留既有 HR／全城管理權限、所有權與可用份數驗證。雪豹價格為 9,000 Merit，每個軍階皆可使用，沿用地面坐騎的出城死亡與休整紀錄。
- `CareerRetirement` 只判斷正式 Commander、既有 Tier 5 十勝與 `completedCareerMissionTemplateIds` 的四門守城勝利；四門勝利包含在十勝內，不讀 lifetime victories，也不因已接受退休而改變歷史資格。`CareerRetirementState` 保存 version 1 的 departing／mobilizing／final-stand／completed、接受時間、戰鬥經過秒數與結局；尚未退休時不寫入此欄位，明確但非法的 checkpoint 使整個 profile 拒絕載入／保存，clone 不共享 state。退休不新增軍階。`startCommanderRetirement` 重用資格，拒絕既有退休、任務／據點任務、賽事、敵對 Town 與非法時間，只 clone／stage departing；`TownScene.startCommanderRetirement` 經既有 `commit` validate／save 成功並發布 profile 後，才套用 runtime；`TownRetirementUI` 在 Commander 的前任指揮官對話中固定顯示退休資格與按鈕，未達標停用，確認不預告伏擊。一般 Town commit 在任何保存或 runtime 副作用前，以輕量 production owner `validateOrdinaryRetirementCommit` 拒絕刪除／改寫既有 checkpoint（含動員 receipt）的任一欄位與新增任務／據點／賽事；相同值的獨立 clone 可正常交易。一般 Town retaliation 自退休開始即由 `canStartOrdinaryTownHostility` 阻擋，ordinary commit 不得新增／替換 hostile townEvent；betrayal 由專屬 `CareerRetirementFinale` owner 驗證。既有 hostile 輸入不得進入 mobilizing。`CareerRetirementMobilization` 專門驗證 departing → mobilizing，先保存再交給 runtime reconciliation，不提供一般 commit bypass。`careerRetirement.phase` 是 reload source of truth；departing 在既有私兵 restore 後執行原生 Follow，保留傷亡、裝備、坐騎與 pending identity，平時 Follow 也納入後續 HR 新聘人員和已完成返營者，停放私人鷹沿原接觸登乘流程恢復。`MissionGuide` 指向北方退役集合區的最近邊界；區域南界在巨鷹原生轉向界線內，不要求抵達最外側世界邊界。
- `CareerRetirementFinale` 驗證完整動員 receipt 與 native snapshots，僅允許 mobilizing → final-stand；`TownRetirementFinaleController` 在北方退役集合區 `x=[-145,145], z=[-350,-250]` 先保存再發布敵對行為（涵蓋原集合點與北方空地，不包含城門附近）；guide 使用同一區域最近邊界，開戰後隱藏。沿用 canonical 237 人及既有 formations／`beginTownHostility`／native eagle combat，不建立 generic Town event、任務結算或軍功獎勵。進入集合區啟動後持續累計 `combatElapsedSeconds` 至 300；後續位置或高度不暫停倒數；玩家死亡沿用 observer 並讓私兵繼續戰鬥，玩家與可戰私兵全部倒下才判 fallen（坐騎不算戰力）。仍有己方戰力時，完整 canonical 敵方人類名冊全部確認死亡立即 escaped，或累計 300 秒 escaped；缺失／未載入敵人不算死亡。Tab 玩家裝備維持既有暫停語意，商店／HR 服務限制不變。terminal candidate 保存前即鎖定並凍結戰鬥，拒絕寫入只重試同一個結局。`retirementRuntime` 與既有 Town／HR／空中 checkpoint 保存玩家、坐騎、傷亡及資源；final-stand 不整補或復活，HR 永久 roster 不刪除。 `areOrdinaryTownServicesPeaceful` 直接讀取保存的退休 phase，讓 final-stand／completed 的服務對話、標記、商店／HR／補給入口與延遲 callback 共用關閉政策，不依賴 generic hostile event 或 controller 初始化；騎乘／下馬與戰鬥控制不受服務 gate 影響。final-stand 亦啟用既有 temporary battlefield mount 借乘資格：原騎手死亡後可借用存活地面馬，仍保留佔用、距離與保留坐騎限制，reload 沿既有 temporary 契約回到步行且保留原馬資源。退休戰鬥事件由既有 `BattleStatsTracker` 分別統計玩家與合法私兵，`retirementRuntime.stats` 保存獨立計數供 HUD／結局顯示；不進入任務軍功結算，已準備的 final-stand 缺少計數即拒讀，避免重置傷害與擊殺。
- `CareerTownEntry` 在建立 TownScene 前分流 completed 到已保存結局，返回主選單不刪檔。確認開始新生涯後僅選擇陣營，不配發永久武器；練習場借用裝備完成後，使用一次性 100 軍功購買第一把武器。已有角色不因缺少 starterWeaponId 重建或要求補選，`CareerCreation.createAndSaveCareer` 原子保存新 Recruit，取消或寫入失敗保留原結局。`CareerRetirementQaProfile` 只建構合法 Commander、10 場 Tier 5 勝利（含 I–V receipts）、100000 可用軍功、玩家全技能滿級的測試檔，配置 30 名 T5 黑貓私兵（15 名 T5 斧／T5 弓／T4 盾，15 名 T5 矛／T4 盾），裝備以實際庫存持有並可正常讀回；`CareerRetirementQA` 僅在 `import.meta.env.DEV` 且 `?careerQa=retirement` 動態載入，重建需確認，Fallen 走真實死亡且全軍覆滅才結算，Escaped 透過正式 owner 保存 295 秒再由玩家或私兵正常存活。Production 不載入 QA 入口或接受該 query 的存檔變更。
- `CareerMissionMeritPolicy`／`MeritCalculator` 管理軍功；Recruit／Soldier／Veteran／Captain board 勝場按任務 Tier 1–4 分開保存，不由當前軍階反推。Duel 擊敗 tier 按 preset 推進，不改 board 勝場。
- `CareerRaceState`／`CareerRaceController` 只使用現行 v3 六場衝刺賽程：戰馬、橘貓、柯基、雪豹、黑／白貓、藪貓／獰貓，勝利軍功依序 100／400／900／1600／2500／3600。正式邀請使用獨立固定獎勵。Session、結果與進度保存 scheduleVersion 3；倒數、路線、死亡、坐騎資源、敵對與結算同格式重整保留。賽果保存成功後才公開，session ID 保證不重發；保存失敗可重試。`CareerRaceReturn` 保存成功才清 Session、移動 Player 或套用延後 TownEvent 結果。沒有 activeRace 是合法空閒狀態；不接受 v1／v2 賽程、歷史 DNF 修復或 legacyRaceProgress。
- 只有正式 Career 結算發軍功；任務外城防兵貢獻保存但不建立新獎勵入口。Captain Eagle 沿 offense mission policy，Stage IX 沿 defense mission policy，其餘現役模板沿各 owner；不新增 Captain／Commander 倍率。`CareerBorrowedIdentity` 保存並驗證 `activeMission.borrowedActorIdentities` 的文化陣營、人物 Tier 與英雄 Profile，重建時先建同一身分及最大 HP，再恢復傷勢；臨時任務裝備不升降人物。借兵與官方兵權在同一次保存成功後才移交 roaming ownership、部署及建立統計；失敗保留相同 ID 重試。結果鎖定凍結 aggregate，延遲投射物保留攻擊時 source membership，NPC 貢獻不進 Player 個人武器 XP。
