# Career faction portraits

`roman-faction.webp` and `viking-faction.webp` are static decorative cutouts from the Roman/Viking entry reference supplied by the user for PR #413. The user explicitly permitted cropping and masking its text-free character regions.

Each portrait uses a manually traced alpha mask, subtle edge feathering and a transparent 640 × 800 canvas. The reference's interface text, buttons, icons and frames are excluded; the original reference is not shipped. No character models or animations were changed. The artwork illustrates faction identity, not starting equipment or an active combat modifier.
