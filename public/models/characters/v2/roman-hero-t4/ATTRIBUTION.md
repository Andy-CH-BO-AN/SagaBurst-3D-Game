# Paladin — Roman T4 appearance

[Paladin](https://sketchfab.com/3d-models/paladin-4f1c320f2cec49dc9bf38c6aad2d8ea9) by [DJMaesen](https://sketchfab.com/bumstrum), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Credit and license are preserved from the supplied `paladin.glb` asset.extras metadata. The source SHA-256 and exact embedded credit are in attribution-evidence.json. The original download is not shipped.

Changes: original weighted body and clothing retained; arms normalized offline to the project rest pose and bone axes; metre scale (1.95 m overall including helmet horns); source swords and scabbards removed; original bastard sword extracted as independent equipment. Source finger curl is baked; static digit weights are collapsed to the hand joints, leaving 31 joints per LOD. Existing Roman T4 animations are retargeted offline with grounded root translations, matching clip names and gameplay events. Three simplified LODs and compressed/resized source textures are exported.

## Frozen foot-axe animation

The game-specific `foot-axe.glb` preserves the exact Roman T4 `axeAttack1HFoot`
previously generated by `createBanditFootAttack` at runtime. Its strike donor is
[Fantasy Bandit](https://www.cgtrader.com/free-3d-models/character/man/fantasy-bandit)
by tokeshi, under the original **CGTrader Royalty Free (no AI)** license;
[original terms](https://www.cgtrader.com/pages/terms-and-conditions).
The donor manifest records permission for incorporated game use and prohibits
standalone redistribution. Those original terms are retained, not replaced by
the Paladin body's CC BY license or a Meshy license.

The donor's original hammer grip/tip and middle-finger landmark establish the
grasp frame. This file contains only the resulting Roman animation tracks,
including the existing Kevin Iglesias idle-derived lower body. It contains no
Bandit body, hammer mesh, skin, or textures. The donor FBX, archive, runtime GLB,
original source attribution, and immutable source-code hashes are recorded in
`foot-axe-provenance.json`. The existing axe event clock, attachment behavior,
and every Roman body GLB remain unchanged.

## Rebuild

From the repository root with Blender 5.2 and the three user-supplied GLBs in one source directory:

```sh
blender -b --python tools/build-paladin.py -- /path/to/source-directory
node tools/retarget-paladin.mjs
```

The retarget step requires Git history containing ae06476. It reads that pinned GLB into ignored output/paladin-build, then emits runtime clips, manifest and audit. See weapons/paladin/ATTRIBUTION.md for the separate equipment credits.

Rebuild or verify the frozen foot-axe clip with the installed project dependencies
and Git history containing `bb517258398423039a7a0dfa983681322c92a51d`:

```sh
node tools/bake-roman-t4-foot-axe.mjs
node tools/bake-roman-t4-foot-axe.mjs --check
```

The tool runs the original registry and all its code dependencies from that
immutable commit, checks the source SHA-256 values, and writes a single small
animation-only GLB. It then loads the current registry and compares every final
animation track, key time, value, interpolation mode, and duration for all three
LODs, including unrelated clips. It rejects target-body changes and any current
Roman T4 request for a Bandit asset. This offline asset audit is not a visual
review or a unit-test/CI suite.
